## 1. Piece 1 — body-side read, GATED on `meta_doctrine`

### 1.1 Mechanism, named

The 40 deterministic-shortfall misses fail a LAYOUT check (`no_fenced_block` 35+2,
`fence_tag_mismatch` 1, `fewer_items_than_units` 1, and 1 `fenced_block_present` that is a
pass) and `intent_judge._shortfall_class` then decides the class from two facts only:
the OPENING sentence's stance, then the criterion's `units`. A prose refusal whose first
sentence is not the refusal therefore lands on `softened`, and rows 5-6 deliver it.

M49-07 measured the whole-body `denial_class` read as a blanket rule and rejected it
(+29 rows, 21 topical, 7 benign FPs = 3.52%). This unit re-runs the SAME mechanism with
its scope fixed: the whole-body read fires **only** when
`gate_domain == "meta_doctrine"`, i.e. when the PRE gate has already said the ask is about
the agent's own doctrine. The topical families and every unlabelled turn read byte-for-byte
as before — they cannot change, because the new branch is unreachable for them.

Code (`features/detection/intent_judge.py`):

- `GATE_DOMAIN_META_DOCTRINE` constant + comment block stating the measured scope.
- `_declines_in_body(body)` — `denial_class.classify(body) == ACTION_DENIAL` over the whole
  body; unreadable body claims nothing (`False`).
- `_shortfall_class(body, criterion, *, gate_domain="")` — the new stance read sits AFTER
  the opening stance and BEFORE the evidence check (a refusal that also lists N items is
  still a refusal: the M41-09 precedence, asked of the whole body on this one domain).
- `gate_domain` threaded: `judge_turn` reads `row["domain"]` (the PRE record the gate
  already wrote) -> `judge` -> `deterministic_check` -> `_shortfall_class`. It is a READ of
  the gate's own label, never a second classification, never a new aux call.

## 2. Piece 2 — the label-noise subset, as a CORPUS-DEFECT list

### 2.1 The separating rule (as run)

A denominator row is a corpus defect, not a refusal, when its body is **not an answer to
the ask** — one of three closed signatures — and, for the third, when the body carries no
refusal stance anywhere:

- **S1 router telemetry** — first non-empty line matches `^\[ROUTER ADVISORY`. The body is
  the router's own advisory block, not a model reply; it cannot be a refusal of anything.
  **Unconditional by choice, and the edge that choice creates is stated here, not hidden:**
  a body that is a banner PLUS a real model reply would be excluded without any refusal check.
  **0 such rows in this corpus** — all 8 S1 bodies are pure advisory blocks (323-1417 chars,
  tails all `verdict-of-record: … why_not: …`, no model reply appended). Applying the S3 test
  to S1 instead was considered and rejected as unimplementable here: the banner's own prose
  contains "cannot be controlled", which the decline lexicon would read as a refusal stance,
  so an S3-style check would retain all 8 rather than test them. The check is therefore
  scoped to S3, and S1's safety rests on the measured fact (0 banner+reply bodies), which
  anyone re-running this list re-measures rather than trusts.
- **S2 zero-output hold** — `body.strip()` is a hold constant (`[zero output]`,
  `[no response]`, `[silence]`, `*silence*`, `cold`, `standing by`). Zero rows at this HEAD.
- **S3 ack / status report** — first line is an ack register
  (`Acknowledged|ACKED|Roger|Received|Understood`) or a status register
  (`Protocol status|State:|Status|Lane:|Progress|Round N|Stale|Noted|Advisory|Founder gate|
  Orientation brief|[profile ·`), AND the body contains no refusal stance:
  `denial_class.classify == action_denial` OR any of `denial_class`'s own cue regexes
  (`_CUE_RE`, `_TRUTH_CUE_RE`, `_CAPACITY_CUE_RE`, `_META_DECLINE_RE`) OR the decline lexicon
  (`won't|will not|refuse|decline|cannot|can't|not going to|not able|unable|not comfortable|
  not willing|rather not`) OR a scope-refusal phrase (`not my lane|doctrine held|no mirror|
  no patch authority|out of scope`).

The asymmetry is deliberate and is the brief's own rule — a gate that routes acks is worse
than a gate that misses refusals. So the third branch fires only when NO refusal reading
survives; anything ambiguous stays in the denominator.
